# Decision Log — 결론이 바뀐 이유

## 1. 작업일 라벨을 용접점 라벨로 사용할 수 있는가?

- 초기 접근: 작업일 불량 여부를 각 용접점에 전가해 이진분류
- 반증: 행 무작위 분할 AUC 0.586이 작업일 그룹 분할에서 0.305로 하락
- 결정: 용접점 지도학습을 최종 모델에서 제외하고 작업일 예측과 비지도 이상탐지로 분리
- 배운 점: 시계열·제조데이터에서는 모델보다 먼저 독립 표본의 단위를 정의해야 한다.

## 2. 복제 구간은 몇 점인가?

- 초기 접근: 가압력 3bar 초과 291점을 이상 구간으로 간주
- 반증: 임계값 없이 행 지문과 최장 연속일치를 사용하자 800점×4일이 완전 동일
- 결정: 총 3,200점, 전체의 26.8%를 학습·평가에서 제외
- 영향: 기존 4/4 탐지 결론이 0/3으로 뒤집혀, 초기 탐지기가 공정이상이 아니라 아티팩트를 탐지했음을 확인

## 3. 어떤 이상탐지 모델을 선택할 것인가?

- 초기 접근: 한 개 고장유형에서 성능이 높은 모델 선택
- 반증: 6개 고장유형으로 확장하자 특정 유형에서 성능 붕괴
- 결정: 11모형×3특징공간×6유형을 같은 조건에서 비교하고 평균이 아닌 최악 유형 AUC로 선택
- 최종: [가압력, 동저항 R, 입열 E] 공간의 kNN 거리, k=3

## 4. 컨포멀 p<0.01은 보장된 임계인가?

- 초기 표현: 오경보율 1% 보장
- 반증: 작업일 사이의 참조분포 이동에서 실제 FPR이 목표의 최대 2.61배
- 결정: `p<0.01`은 명목 임계로 표현하고, 팽창계수 반영 `p<0.0038`도 근사 운영 후보로 한정
- 배운 점: 이론적 보장은 가정과 함께 말해야 하며, 운영 분포에서 가정을 다시 검증해야 한다.

## 5. 복잡한 순차탐지기가 일 단위 공정 이동에도 최선인가?

- 결과: kNN+컨포멀+CUSUM은 복제 제거 후 실제 이동일 0/3 탐지
- 대조: 가압력 일별 중앙값 2σ 관리도는 3/3 탐지, 안정일 0/5 오경보
- 결정: 용접점 탐지기는 국소 이탈과 재검사 우선순위, 관리도는 일 단위 수준 이동에 사용
- 배운 점: 모델 복잡도가 아니라 이상이 발생하는 시간척도에 맞춰 도구를 선택해야 한다.
